# Local Development

Clone repository:

```bash
git clone https://github.com/RaphaelParmentier/raphael-portfolio.git
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Open:

```txt
http://localhost:3000
```
